在衣橱间，慢慢来

  1. 一次上传多件

    可批量选图，名字选填。文件名有“半裙”“dress”等词时会建议分类，普通相机文件名会先放到“待整理”。

  2. 用干净的单品图

    透明 PNG、平铺图或白底图更适合拼搭。透明图片会裁掉空白；真人照片会保留人物。

  3. 自由搭一搭

    点单品的 ＋ 加入画布。拖动位置，用右下角圆点缩放，也可在下方调整大小、旋转、翻转和层次。

  4. 补充单品档案

    点击衣服图片或名称查看藏品档案，再点「编辑档案」或右上角铅笔，补充单品与购入信息、秀款年份、系列、Look 编号、资料来源和收藏故事。可添加最多 12 张秀场、实物细节或穿着附图，并导出 PNG 纪念卡；价格可选择隐藏。所有资料均可留空。完整档案会随备份一起保留；连接 GitHub 后也会一起同步。

  5. 查看衣橱价值与品牌

    衣橱顶部汇总已购入单品的实际花费与原价，并显示未填价格的数量。不同币种分开统计，想买和示例衣服不计入。用品牌下拉框筛选，或直接搜索品牌名。

  6. 连接私有 GitHub 衣橱

    点右上角 GitHub 同步，连接独立的私有数据仓库。开启自动同步后，新照片、单品修改和已保存的搭配会同步；未保存的画布草稿保存在本机。换设备后连接同一仓库即可加载。遇到冲突时选择保留的版本。

  7. 保存喜欢，记得备份

    搭配保存后可重新打开。导出图片用于分享；完整备份用于换设备或恢复衣橱。
